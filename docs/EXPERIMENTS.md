# Experiment Log — IA-test

This file records every experiment the system runs on itself.
Each entry documents what was tested, why, and what actually happened.

**Rule:** An experiment that produces a convincing answer is not the same
as an experiment that produces a *correct* answer. Document both.

---

## Template

```
## EXP-NNN — Title

**Date:** YYYY-MM-DD
**Phase:** N
**Hypothesis:** What we expected to happen
**Procedure:** What we actually did
**Expected outcome:** Specific measurable result
**Actual outcome:** What we observed
**Conclusion:** What this tells us
**Confidence change:** Which memory entries were updated and how
**Branch:** experiment/auto-... (if self-modification)
**Status:** PASSED | FAILED | INCONCLUSIVE
```
